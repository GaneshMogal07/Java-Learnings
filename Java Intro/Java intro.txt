3. What is Platform Independent?

Very important concept 🔥

Java follows:

Write Once, Run Anywhere (WORA)

That means:

If you write Java code on Windows
You can run it on Linux or Mac without changing code.

How?

Because Java uses:

🟢 JDK – Java Development Kit

🟢 JVM – Java Virtual Machine

🟢 JRE – Java Runtime Environment

We will learn these later in detail.


4.Difference Between print() and println():-

A.println() → prints and moves to next line

eg:-

System.out.println("Java");
System.out.println("Programming");

output:-

Java
Programming

B.print() → prints in same line
 
eg:-
System.out.print("Java ");
System.out.print("Programming");

output:-
Java Programming
